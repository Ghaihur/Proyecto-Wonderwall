# Project Wonderwall

## Estado

🟡 En desarrollo

---

## Objetivo

Construir una experiencia elegante, minimalista y sincera para pedir perdón.

No buscamos impresionar.

Buscamos transmitir.

---

## Filosofía del proyecto

- Cada animación debe tener un propósito.
- Menos es más.
- Código limpio.
- Sin librerías CSS.
- HTML semántico.
- JavaScript puro.
- Mobile First.
